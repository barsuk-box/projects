# Каталог проектов Ильи

Публичный React-дашборд: текущие проекты, будущие идеи, фильтры и поиск, подробные карточки, светлая и тёмная темы, Blender / glTF-сцена с анимацией и параллаксом.

Сайт: https://barsuk-box.github.io/projects/

## Запуск

Требуется Node.js 22.12+.

```sh
npm ci
npm run dev
```

Открыть адрес с путём `/projects/`. `npm run build` проверяет реестр и создаёт `dist/`. `npm run preview` показывает production-сборку.

## Карточки

Данные: `src/projects.json`. [Правило обновления](docs/CATALOG-RULE.md), [план](docs/PLAN.md).

```sh
node scripts/upsert-project.mjs path/to/public-card.json
npm run build
```

Публично размещаются только краткие описания проектов. Plaud-аудио, транскрибации, документы и финансовые данные не входят в репозиторий. Реестр не подключается к закрытым проектам и не раскрывает их файлы. Проекты и идеи имеют разные статусы.

## 3D

Исходная модель: `assets/orbit.blend`, воспроизводимый скрипт: `assets/create-scene.py`. Сцена создана в Blender 4.5 LTS и экспортирована с keyframe-анимацией в `public/orbit.glb`. Three.js загружается отдельным модулем. `public/orbit-fallback.png` — рендер той же сцены для устройств без WebGL.

```sh
blender --background --python assets/create-scene.py
```

Учтены `prefers-reduced-motion`, кнопка паузы, остановка обновлений невидимой сцены и ограничение плотности пикселей. Движение мыши и скролл управляют параллаксом. Шрифт Manrope с кириллицей хранится в сборке, сторонние шрифтовые сервисы не нужны.

## Темы и мобильная версия

При первом визите тема следует системной настройке. Переключатель сохраняет выбор локально; доступен и при запрете localStorage. На ширине до 740px отключены горизонтальная прокрутка и выделение текстов; поле поиска остаётся редактируемым. Полноэкранные диалоги ограничены высотой viewport и прокручиваются вертикально.

## Публикация

GitHub Pages настроен на GitHub Actions. Push в `main` запускает `.github/workflows/pages.yml`; секреты для развёртывания не требуются. Публикация из PR не выполняется. Для обновлений создавайте ветку `codex/...`, проверяйте изменения и следуйте правилам репозитория.

Фотография предоставлена владельцем для этого сайта. Её наличие в открытом репозитории не означает разрешения на стороннее использование. Локальные заметки Obsidian и глобальные настройки Codex в репозитории не хранятся.
