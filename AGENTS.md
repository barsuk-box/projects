# Работа с каталогом

- Сохранять React, GitHub Pages и базовый путь `/projects/`.
- Карточки изменять в `src/projects.json` по `docs/CATALOG-RULE.md`.
- Не включать приватные данные и материалы исходных проектов.
- После изменения проверять `npm run build` и обе темы на desktop/mobile.
- Сохранять поддержку reduced motion, отсутствие горизонтального скролла на мобильных и редактирование поиска.
- Не добавлять секреты и глобальные персональные инструкции в репозиторий.
